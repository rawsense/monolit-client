  • Экспорт структуры в JSON и хранение в Git

import { Coreless } from 'coreless'const cms = new Coreless({ project: 'zerno' })const page = await cms.getPage('home')page.text('hero/title')   // «Кофе, ради которого…»page.table('menu/items')  // строки каталога

Вопросы

Частые вопросы

Нужно ли уметь программировать?

Нет. В панели только поля для текста и загрузка картинок.

Можно подключить уже готовый сайт?

Да, если у сайта есть разработчик. Он отметит, какие тексты и картинки берутся из Coreless. Переделывать сайт целиком не нужно.

Что делать, если разработчик уйдёт?

Контент отдаётся по стандартному REST API. Новый разработчик разберётся в проекте за вечер.

Чем Coreless отличается от Tilda и WordPress?

В конструкторе дизайн ограничен шаблонами, а в WordPress у редактора доступ ко всему сайту. В Coreless дизайн может быть любым, а редактор меняет только контент.
